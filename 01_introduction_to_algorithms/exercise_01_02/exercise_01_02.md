# Exercise 1.2 — Doubling the List Size

## Introduction

Solution to Exercise 1.2 from the book *Grokking Algorithms, Second Edition*.

## Problem

The problem statement is omitted due to copyright. See Exercise 1.2 in the referenced book.

## Solution

Doubling the size of the list from the previous exercise increases the number of names from 128 to 256.

Since binary search eliminates half of the remaining candidates at each step, only one additional step is required to eliminate the extra 128 names.

The maximum number of steps therefore increases from 7 to 8.

## Answer

8 steps
