# Exercise 2.1 — Finance Tracker

## Introduction

Solution to Exercise 2.1 from *Grokking Algorithms, Second Edition*.

## Problem

The problem statement is omitted due to copyright. See Exercise 2.1 in the referenced book.

## Solution

In the simplified comparison used in this exercise, it would be best to use a linked list. The app has many insertions and only needs to read all the expenses occasionally. Inserting into a linked list is efficient when the insertion point is known, and at the end of the month the app can traverse the list and sum the expenses.

## Answer

linked list
